Vývoj iOS aplikace na míru

SwiftUI • MapKit • API integrace • Real-time aplikace

O mně

Jsem iOS vývojář se specializací na SwiftUI a nativní iOS aplikace. Mám několik publikovaných aplikací v App Store s aktivními uživateli po celém světě. Specializuji se na aplikace vyžadující real-time zpracování dat, GPS integraci a pokročilé API komunikace.

Publikované aplikace

CB Cluster DX

Real-time monitoring CB DX spotů s integracií CRX Network API. MapKit vizualizace propagace signálu.

TropoDX

Sledování troposférické propagace s výpočty propagačních podmínek a meteorologickými daty.

Locator DX

Nástroje pro práci s Maidenhead grid lokátory, včetně GPS integrace a mapových výpočtů.
